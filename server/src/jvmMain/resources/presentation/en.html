macOS installation, step by step

Download and inspect the official script before running it. It installs the app in Applications and opens Screenshare.

curl -fL https://github.com/RafaelrainBR/screenshare-kotlin-js/releases/latest/download/install-macos.sh -o install-macos.sh
less install-macos.sh
bash install-macos.sh

Allow Screen Recording, microphone and camera as needed. If capture stops after an update, remove and re-add the app in Privacy & Security.

Before you join.

Do I need an account?

No. Enter your name and create a room or join with a code. Anyone with the code can join; share it with people you trust.

Can I share any audio?

In a browser, it depends on your system and the source selected in the picker. Desktop offers computer or application audio. Protected content may be black or silent.

Is chat saved?

The server holds messages in memory while the room exists. They are not a permanent archive and can disappear when the room ends or the server restarts.

Which version should I install?

This page recommends the stable Tauri desktop app. The experimental native variant is separate and is not the recommended download here. Browse all releases
