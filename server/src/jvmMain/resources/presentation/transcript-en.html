How to share your screen in a browser

Browser recording, no audio.

  1. Screenshare: your screen and conversation in one room.
  2. Enter your name. Leave the code empty to create a room.
  3. Copy the code so another person can join the same room.
  4. Keep the conversation alongside the stream.
  5. A real browser tab, streamed to the other peer over WebRTC.
  6. Focus the stream and keep the previews nearby.
  7. Choose a profile for your next share: games, video or code.
  8. Try screen-share.fly.dev/about. Browser, Windows and macOS.
