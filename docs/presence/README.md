# Presença do Screenshare

Materiais preparados em **18/10/2026**, a partir do [plano de presença](../project-presence-plan.md). São documentos de execução; publicações e testes com pessoas continuam pendentes.

Mensagem: **Compartilhe a tela e converse na mesma sala, pelo navegador ou pelo desktop.**

Referência para download: [v0.11.1 estável](https://github.com/RafaelrainBR/screenshare-kotlin-js/releases/tag/v0.11.1). A [native-v0.1.0](https://github.com/RafaelrainBR/screenshare-kotlin-js/releases/tag/native-v0.1.0) é experimental e não deve ocupar o botão principal. A interface do aplicativo está em português brasileiro.

Antes de divulgar, concluir a validação real da página, do vídeo e dos downloads. O usuário precisa escolher os textos e canais e autorizar explicitamente o envio. Convites para testes também não foram enviados. O responsável por acompanhar o feedback deve ser definido antes da publicação.

Não há automação nem calendário de envio. Após a primeira divulgação, registrar manualmente o horário e os links em [outreach-drafts.md](outreach-drafts.md), e repetir a coleta após 7 e 14 dias; a janela de tráfego do GitHub é móvel.
