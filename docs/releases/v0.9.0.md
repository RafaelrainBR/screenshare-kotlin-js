## Changes since 0.8.0

- New “Sala noturna” visual identity, Barlow fonts, logo and desktop icons.
- Sharing presets for games, video and text, with advanced frame rate, bitrate and encoder priority settings.
- Change sharing settings live from the footer without restarting the share.
- Fix stale shares freezing or graying remote screens; improve WebRTC negotiation and ICE recovery.
- Start login sessions in the tray without flashing a window; the macOS Dock icon follows the full window.
- Update Kotlin, Gradle, Ktor, Kotest, Tauri and native capture dependencies.

## Install

**macOS (Apple Silicon):**

```sh
curl -fsSL https://github.com/RafaelrainBR/screenshare-kotlin-js/releases/latest/download/install-macos.sh | bash
```

**Windows (x64):** use `Screenshare_0.9.0_x64-setup.exe`, the `.msi`, or `Screenshare_0.9.0_x64-portable.exe` (requires WebView2).

`SHA256SUMS` contains checksums for all downloads.

## Known limits

Builds remain unsigned on Windows and ad hoc signed without notarization on macOS. SmartScreen may warn. Real-device screen/audio capture, Windows 11 and macOS permissions need manual verification. Audio source selection is fixed when sharing starts; re-share if an app starts new audio processes. macOS shows its screen-recording indicator.
