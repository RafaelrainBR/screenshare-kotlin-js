# Screenshare 0.11.1

## O que melhora para quem usa

- O aplicativo instalado verifica novas versões e oferece atualização dentro do app. Saia da sala antes de instalar e reiniciar.
- Se câmera ou microfone forem bloqueados, a recuperação de permissões pode abrir as configurações de privacidade do sistema.
- A negociação de vídeo evita transceptores já encerrados, corrigindo uma falha nesse caminho do WebRTC.

## Instalar

- **Windows x64:** prefira `Screenshare_0.11.1_x64-setup.exe`. MSI e EXE portátil também estão disponíveis; o portátil requer WebView2 e não se atualiza sozinho.
- **macOS Apple Silicon:** use `install-macos.sh` após ler o script, ou siga o [guia de instalação](https://github.com/RafaelrainBR/screenshare-kotlin-js/blob/master/docs/usage.md#macos-installation).
- `SHA256SUMS` permite conferir os arquivos baixados.

Windows continua sem assinatura de código. macOS usa assinatura ad hoc, sem notarização. Se a captura parar após atualizar no macOS, remova e adicione novamente o Screenshare em Gravação de Tela.

Esta é a linha estável desktop Tauri. A pré-release `native-v0.1.0` é uma variante experimental separada.

## Changes in English

Installed desktop builds offer in-app updates and can open OS privacy settings after camera/microphone denial. This release also avoids stopped transceivers during video negotiation and shares native capture through the extracted Rust crate.

Prefer the Windows NSIS installer; the portable EXE requires WebView2 and updates manually. Apple Silicon Macs use the documented install script. Windows binaries are unsigned; macOS is ad hoc signed without notarization. Re-add Screen Recording permission after an update if capture stops working.

Full changelog: https://github.com/RafaelrainBR/screenshare-kotlin-js/compare/v0.10.0...v0.11.1
