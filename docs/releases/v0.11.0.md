# Screenshare 0.11.0

- The desktop app now checks GitHub Releases at startup and offers to download, install and restart from inside the app. Installing is blocked while you are in a room.
- Media permission recovery opens the operating system's privacy settings directly.
- macOS: after an update, if screen capture stops working, remove Screenshare from Screen Recording and add it again.

**Install this version manually** (NSIS installer on Windows, `install-macos.sh` on macOS). Later versions arrive through the in-app update banner.
The portable EXE does not update itself.

Windows x64: NSIS installer, MSI or portable EXE (requires WebView2).
macOS Apple Silicon: use the bundled `install-macos.sh` or the app archive.
`SHA256SUMS` contains checksums for all downloads.

Windows builds remain unsigned; macOS uses ad hoc signing without notarization.

Full changelog: https://github.com/RafaelrainBR/screenshare-kotlin-js/compare/v0.10.0...v0.11.0
