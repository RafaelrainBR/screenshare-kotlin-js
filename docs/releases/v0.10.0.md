# Screenshare 0.10.0

- Refine room behavior: quieter status, Enter to send chat, tray icons and participant rail.
- Exclude Discord from Windows system audio capture.
- Update and patch build and desktop dependencies to address security alerts.
- Create release tags and publish packages directly from the manual GitHub Actions workflow.

Windows x64: NSIS installer, MSI or portable EXE (requires WebView2).
macOS Apple Silicon: use the bundled `install-macos.sh` or the app archive.
`SHA256SUMS` contains checksums for all five downloads.

Windows builds remain unsigned; macOS uses ad hoc signing without notarization.
Real-device installation, screen/audio capture and permissions require manual smoke testing.

Full changelog: https://github.com/RafaelrainBR/screenshare-kotlin-js/compare/v0.9.0...v0.10.0
